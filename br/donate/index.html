Apoie

Gratuito e de código aberto. Mantido vivo por pessoas como você.

O Eizport é gratuito e de código aberto, sem versão paga segurando recursos — e continua assim enquanto o apoio cobrir o tempo necessário para desenvolver, manter e dar suporte com qualidade. Se ele te poupou uma tarde reenviando imagens e remontando uma página inicial, uma doação o mantém cuidado, testado a cada versão do WordPress e crescendo.

Doar

  • Apoia.se

    Apoio mensal em reais, a partir de R$ 5. O nome de cada apoiador vai na página de apoiadores.

    Brasil

    Apoiar pelo Apoia.se

Doações são presentes: não compram suporte, recursos nem prioridade. Todo mundo recebe o mesmo plugin, de graça. Quem doa recebe um agradecimento na página de apoiadores.

Outras formas de ajudar

  • Dê uma estrela no GitHubEstrelas ajudam outras pessoas a encontrá-lo.
  • Relate o que quebrarUma issue clara vale mais que uma solicitação de recurso.
  • Melhore a documentaçãoCada página tem um link “Editar esta página no GitHub”.
  • Conte para alguémA próxima pessoa que for levar um site WordPress vai agradecer.
